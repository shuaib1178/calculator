## 2026-08-19 - Initial Page Load Feedback in HTML Shell
**Learning:** Inserting an accessible static loader directly inside `#root` with inline styles prevents blank page flashes during initial script parsing while seamlessly being replaced when React mounts.
**Action:** Use inline styles, brand colors (`#054f49` on `#fcfbfd`), and SMIL SVG animations with `role="status"` in static HTML templates.
