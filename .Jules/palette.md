## 2026-07-12 - Initializing Palette Journal
**Learning:** Reusable UX Pattern: Implementing a CSS-only loading state within the 'index.html' #root div (using a flex container, brand-colored spinner, and 'role="status"' text) provides immediate feedback while the JavaScript bundle loads.
**Action:** Always consider adding a skeleton or spinner in the root div for React/Vite apps to improve perceived performance.
