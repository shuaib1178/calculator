# Palette's Journal

## 2026-10-30 - Initial Loader Pattern
**Learning:** Adding an accessible, inline CSS/SVG loading state inside the static HTML root element provides immediate feedback and prevents layout jump/FOUC before the JavaScript bundle initializes.
**Action:** Use brand-aligned inline styling and SMIL/CSS SVG spinners inside `#root` for instant user feedback on initial page loads without introducing external CSS bundle dependencies.
