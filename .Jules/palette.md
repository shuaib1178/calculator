## 2026-08-08 - Accessible Color Contrast and Initial Loader UX
**Learning:** The brand muted color ('#c0c1c0') has a contrast ratio of only ~1.93:1 against the light page background ('#fcfbfd'), which is a severe violation of WCAG AA accessibility guidelines (requiring at least 4.5:1 for regular text). Correcting this to '#4b5563' yields a highly accessible ~7.7:1 contrast ratio while keeping a cohesive muted gray tone. Furthermore, without an initial loader, the app displays a blank page during JS bundle downloads. Embedding an inline SVG spinner inside the '#root' container prevents flash-of-unstyled-content (FOUC) and provides immediate, screen-reader-friendly status feedback ('role="status"', 'aria-live="polite"').
**Action:** Always verify color contrast on custom design tokens and use inline-styled loaders within the React mounting container for instant, accessible initial feedback on web apps.
