# Palette Journal

## 2026-07-09 - [Accessibility] Insufficient Contrast in Muted Text
**Learning:** The default 'brand.muted' color (#c0c1c0) provides only a 1.93:1 contrast ratio against white backgrounds, failing WCAG AA standards (4.5:1). This makes muted text or borders nearly invisible to users with visual impairments.
**Action:** Update 'brand.muted' to #4b5563 (Tailwind gray-600) which provides a 5.11:1 ratio, ensuring accessibility while maintaining a 'muted' aesthetic.
