## 2026-10-20 - Initial Loader Pattern
**Learning:** Implementing an initial SVG loading indicator with SMIL animation and inline styles directly inside `#root` in `index.html` provides immediate, flicker-free feedback without relying on external CSS bundles before React mounts.
**Action:** Use inline styles with brand primary color (`#054f49`) and background (`#fcfbfd`) along with `role="status"` and `aria-label` for lightweight, accessible HTML-only loaders.
