# Palette's Journal - Critical UX & Accessibility Learnings

## 2026-06-29 - [WCAG AA Contrast Compliance]
**Learning:** The previous 'brand.muted' color (#c0c1c0) failed WCAG AA contrast standards. Using #4b5563 ensures a minimum 4.5:1 ratio on light backgrounds.
**Action:** Always check color contrast for design tokens against expected background colors.
