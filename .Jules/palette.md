## 2026-10-09 - Accessible Initial Loader for React SPA
**Learning:** Adding an initial loading state inside `<div id="root">` with inline flexbox, SMIL-animated SVG, and `role="status"` provides immediate visual feedback and screen-reader context before the JS bundle mounts.
**Action:** Use a nested wrapper `<div>` inside `<div id="root">` with inline system font styles and brand color tokens (`#054f49`, `#fcfbfd`).
