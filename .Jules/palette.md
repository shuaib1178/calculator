# Palette's Journal

## 2026-08-24 - Initial Loader for Static Root
**Learning:** Adding a CSS/SVG inline loader inside `<div id="root">` with `role="status"` and `aria-label` provides immediate feedback during web bundle downloads without triggering FOUC or requiring extra CSS dependencies.
**Action:** Always use inline SVG animations (SMIL) and standard system fonts for zero-dependency static HTML loading screens.
