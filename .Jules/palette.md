# Palette Journal

## 2026-07-10 - Initial Load UX Pattern
**Learning:** Implementing a CSS-only loading state within the 'index.html' #root div (using a flex container, brand-colored spinner, and 'role="status"' text) provides immediate feedback while the JavaScript bundle loads, especially in environments where the 'src' directory might be missing or slow to load.
**Action:** Use a flex container with a spinner and accessible text inside #root.
