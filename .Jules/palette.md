# Palette Journal

## 2026-07-10 - Improved Color Contrast for Muted Text
**Learning:** The default 'brand.muted' color (#c0c1c0) had a contrast ratio of approximately 1.93:1 against the page background (#fcfbfd), which failed WCAG AA standards (minimum 4.5:1).
**Action:** Updated 'brand.muted' to #4b5563, which provides a contrast ratio of approximately 5.11:1, ensuring better readability and accessibility.
