## 2026-01-10 - Color Contrast Standard for Muted Text
**Learning:** The 'brand.muted' color in 'tailwind.config.js' should be set to '#4b5563' or darker to ensure WCAG AA contrast standards (ratio >= 4.5:1) on white/off-white backgrounds like 'brand.page' (#fcfbfd).
**Action:** Use '#4b5563' for muted text to achieve a safe contrast ratio of 5.74:1, ensuring accessibility for users with visual impairments.
