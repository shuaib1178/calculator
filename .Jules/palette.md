## 2026-09-14 - Inline SVG SMIL Initial Loader in Root Container
**Learning:** Nesting a flexbox loader container with an SVG inline SMIL spinner and `role="status"` inside `<div id="root">` provides immediate, flicker-free feedback before JS execution without requiring external CSS or custom `<style>` blocks.
**Action:** Place accessible inline SVG loaders directly within `#root` in HTML templates to ensure seamless transition when React mounts.
